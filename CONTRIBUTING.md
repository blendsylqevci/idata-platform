# Contributing to iData+

## Before you commit

Run a staged privacy review. Do not commit owner-private material.

Checklist:

- No contracts, offers, prices, payment terms, or commercial negotiations.
- No SEF IDs, certificates, private keys, `.env`, tokens, credentials.
- No raw PRO DATA backups/exports or real customer/supplier/person data.
- No accountant/client files unless sanitized and explicitly approved.
- No screenshots/manifests exposing private values or paths.
- No files from gitignored private folders.

If any item is uncertain, stop and ask Blend.

## Source of truth

Use the hierarchy in `PROJECT_RULES.md`. Canonical docs must cite evidence or reason for implementation-critical claims.

## Pull requests

Every PR must include privacy confirmation, tests/checks, and scope summary.
