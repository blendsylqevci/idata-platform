## Critical warning

Do not put owner-private or client-sensitive material into GitHub. Private GitHub still means visible to collaborators.

Never commit:

- contracts, offers, prices, payment terms, maintenance terms;
- SEF identifiers/certificates/keys/passwords;
- raw PRO DATA exports/backups or real client/accountant data;
- screenshots or manifests containing sensitive paths/values.

Use gitignored private-local folders for sensitive evidence. If unsure, ask Blend/Codex before copying or committing.

## Claude Code role

Claude Code builds and edits inside approved scope. Codex quality-gates. Do not bypass the privacy gate or canonical split process.

Before proposing a commit, provide:

- changed files;
- privacy-sensitive scan result;
- tests/checks run;
- any open risks.
